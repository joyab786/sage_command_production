# SageCommand OS — Changelog (Release Notes)

## V2.0 (Current Release) - Enterprise Architecture Overhaul

### 🚀 Major Features
- **Frontend Overhaul:** Deprecated the monolithic UI. Rebuilt the frontend into an 11-component modular orchestrator shell using Next.js.
- **Cyberpunk Dark Mode Aesthetic:** Implemented a premium `#020202` aesthetic with neon cyan and purple accents, featuring fluid micro-animations via Framer Motion.
- **React Flow Neural Pathways:** Integrated interactive visualization of the 9-node agent topology with animated, glowing data streams.
- **Blast Radius Mapping:** Added dynamic CSS pulse rings to visualize the impact of an anomaly across cascading downstream systems.
- **Security Agent (DEFCON 1):** Introduced a specialized LangGraph node to intercept malicious queries, triggering a red UI lockdown event.
- **Timeline Reversion Cortex:** Added a Time Travel UI modal to inspect LangGraph SQLite checkpoints.

### 🔧 Backend Enhancements
- **Multi-Modal Diagnostics:** Integrated Vision models to ingest and analyze hardware damage via Base64 payloads.
- **Resilient Failover:** Built an auto-failover mechanism from Groq (Llama-3) to Google Gemini to prevent inference timeouts.
- **Simulated Factory Generator:** Added `simulate_factory.py` to continuously inject random anomalies (supply chain delays, hardware faults) for testing.
